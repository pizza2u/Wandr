# 🗺️ Wandr — Planejamento de Viagem Inteligente

O **Wandr** é uma aplicação web "single-file" (HTML, CSS e JavaScript puros em um único arquivo) que gera roteiros de viagem dinâmicos baseados no destino, na quantidade de dias e no mês escolhido pelo usuário. 

🧠 **Contexto do Projeto:** Este projeto foi criado como um experimento prático para testar as capacidades de geração de código e estruturação lógica do modelo de inteligência artificial **Claude**, utilizando uma abordagem de *few-shot prompting* (poucos comandos).

## ✨ Funcionalidades

* **Geração Dinâmica de Roteiros:** Cria cronogramas diários detalhados para viagens de 1 a 30 dias.
* **Modos de Viagem:** Permite escolher entre explorar um **País inteiro** (distribuindo os dias entre várias cidades automaticamente) ou focar em uma **Cidade específica**.
* **Lógica de Sazonalidade Inteligente:** O sistema avalia o mês escolhido e fornece dicas de clima, alertas de multidões e eventos específicos da época para aquele destino (ex: Sakura no Japão, Monções na Tailândia).
* **Vasto Banco de Dados Local:** Inclui mais de 80 países e suas respectivas cidades, agrupados por continente.
* **UI/UX Premium:** Interface moderna com tema escuro (Dark Mode), tipografia elegante (Fraunces e Mulish), elementos glassmorphism e design totalmente responsivo (Mobile-first).

## 🛠️ Tecnologias Utilizadas

Este projeto não possui dependências externas (como React, Vue, NPM, etc), focando na simplicidade e performance:

* **HTML5:** Estruturação semântica.
* **CSS3:** Variáveis nativas (Custom Properties), CSS Grid, Flexbox e animações `@keyframes`.
* **Vanilla JavaScript (ES6+):** Lógica de estado, manipulação do DOM e bancos de dados em objetos/arrays locais.
